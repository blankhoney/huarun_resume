# 面试截图清单

## 必备截图

| 截图 | 内容 | 目的 |
| --- | --- | --- |
| 首页 | 三个主入口：拍照添加、今日提醒、问一问 | 证明 Demo 是可体验产品 |
| 上传与确认页 | 图片预览、识别字段、来源片段、确认勾选 | 证明 AI 结果不会自动保存 |
| 电子药箱 | 药品卡片、提醒时间、状态 | 证明药品已进入管理闭环 |
| 提醒记录页 | 1 分钟 Demo 提醒、四个状态按钮、7 天摘要 | 证明提醒和记录闭环可用 |
| 问答页 | 普通问题来源回答、红色问题拒答 | 证明医疗安全边界 |
| System Prompt | 药品整理助手安全规则 | 证明模型不是开放式医疗聊天 |
| AI 工作流 | 固定 Demo 文本输入、MiniMax 抽取、人工确认、问答安全分级、QA 来源兜底 | 证明有工程化链路 |
| 数据 Schema | `MedicineExtraction`、状态枚举、安全标签 | 证明结构化约束 |
| API 路由 | `src/huarun_app/main.py` 中的扫描、确认、药箱、提醒、记录、问答接口 | 证明不是静态假页面 |
| 部署配置 | Docker Compose 和 Caddyfile | 证明可部署到 Debian 13 VPS |

## 面试材料文字说明

可以配合截图使用以下简短说明：

“这个 MVP 的核心不是替医生做决策，而是降低中老年人和家属建立电子药箱的输入成本。当前 Demo 使用固定说明文本展示 AI 整理链路，所有药名、用法和提醒时间都必须人工确认。问答部分按风险分级处理，高风险问题直接拒答并建议咨询医生或药师。”

## 不建议提交的截图

- 真实 API Key 或服务器 `.env`。
- 上传目录中的真实个人药品照片。
- 包含私人域名配置、服务器 IP、Cookie 或 session secret 的终端输出。
- 模型完整日志中可能含健康信息的原始内容。
